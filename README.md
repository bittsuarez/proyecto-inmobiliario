# Proyecto Inmobiliario — Cristian Suárez

Captación de clientes interesados en terrenos, propiedades usadas y otros
inmuebles, a través de redes sociales (Facebook, Instagram, TikTok) que
enlazan a una landing page con formulario de contacto y agenda de llamada.

## Dónde está cada cosa

- `BRIEF.md` — la ficha central del negocio (nombre, contacto, zona, colores).
  Es la fuente de verdad: de aquí sale el contenido de la landing, las bios
  y los posts. **Llenar esto primero.**
- `redes-sociales/` — bios para cada red y calendario de publicaciones.
- `media/fotos/` y `media/videos/` — subir aquí el material propio
  (fotos de propiedades, videos) para que se pueda editar/adaptar a cada red.
- `landing/` — el código de la página de aterrizaje (se arma en el Paso 2).

## Hoja de ruta

1. **Llenar `BRIEF.md`** con los datos del negocio.
2. **Construir la landing page** (`landing/`) con formulario y agenda de
   llamada, usando los datos del brief.
3. **Crear las cuentas** de Facebook, Instagram y TikTok (esto lo hace
   Cristian) usando las bios de `redes-sociales/bios.md`.
4. **Preparar el banco de contenido inicial** en
   `redes-sociales/calendario-contenido.md`, subiendo fotos/videos a `media/`.
5. **Publicar**, siempre enlazando a la landing.
6. **Medir y ajustar** el calendario según qué publicaciones traen más leads.
